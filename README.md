## HelicopterFE.lua

FE-skripti (R6), joka muuttaa oman hahmosi pieneksi helikopteriksi. Ei luo uusia parteja - raajat asetetaan uusiin paikkoihin joka frame, joten kaikki pelaajat nakevat sen (100% FE).

- Vartalo = runko (makuulla), paa = ohjaamo, oikea kasi = masto selasta ylos, oikea jalka = paapotkuri, vasen kasi = hantapuomi, vasen jalka = hantapotkuri
- WASD = liiku, HYPPY = nousu (paapotkuri kihahtaa), LASKU-nappi / CTRL = lasku (potkurit hiljenevat). LASKU-nappi ilmestyy hypynapin viereen.
- Eteenpain kiihdyttaessa nokka kallistuu alas ja hantapotkuri pyorii kovempaa, sivuttaisliike kallistaa runkoa
- Moderni GUI: lapinakyva, raahattava, pienennettava (- nappi), CRASHOUT-animaatio (paa ja kadet taakse, tarkina, potkurit sahaavat)
- RightShift = piilota/nayta GUI
- Vaatii R6-avatarin
